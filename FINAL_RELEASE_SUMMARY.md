## Deployment Instructions

### Quick Start (Automated)

```bash
# Clone the repository
git clone https://github.com/NaTo1000/ArciTEK.AI.git
cd ArciTEK.AI

# Run automated deployment
./deploy.sh
```

### Manual Deployment

```bash
# 1. Setup environment
./startup.sh

# 2. Configure API keys
cp .env.template .env
# Edit .env with your API keys

# 3. Run tests
./run_tests.sh all

# 4. Start monitoring
./monitor.py start --interval 60

# 5. Deploy to production
./deploy.sh
```

### Docker Deployment

```bash
# Build and run
docker build -t arcitek-ai:7.0.0 .
docker run -d -p 5000:5000 -p 8000:8000 --name arcitek-ai arcitek-ai:7.0.0
```

### Kubernetes Deployment

```bash

./deploy.sh
# Select option 7 (Kubernetes)
```
