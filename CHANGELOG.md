## Migration Guides

### From Pre-Release to 1.0.0

This is the first stable release. If you were using any pre-release versions:

1. **Backup your configuration:** Save any custom settings and API keys
2. **Fresh installation:** We recommend a clean installation for 1.0.0
3. **Run configuration wizard:** Use `./startup.sh config` to set up API keys
4. **Validate setup:** Run `python3 scripts/validate_keys.py` to verify
